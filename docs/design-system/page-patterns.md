# 页面模式映射

按页面类型约定默认交互，具体页面只在有真实业务差异时偏离，并记录例外。

## 1. 资源列表（任务、素材、审核、分配、设备、用量明细）

适用：`TaskCenterPage`、`MaterialsPage`、`QualityPage`、`HubAssignmentsPage`、`HubDevicesPage`、`ModelUsageDialog` 明细。

- 标题：`PageHeader` 一个 h1；不重复页面名与模块名。
- 操作：主操作唯一且靠右；刷新为次级；危险/批量操作按范围分组。
- 统计卡：只对后端真实支持筛选的状态可点击；选中态用 `aria-pressed`，再次点击恢复全部。
- 筛选：`FilterToolbar` + `SearchInput`；有活动条件时显示清除入口与当前范围；清除筛选不误清选择。
- 表格：`AppDataTable` 统一列宽/省略/固定列；名称可点击进入详情；选择与行点击语义分离。
- 选择：跨页保留；`BulkActionBar` 常显数量、操作与清空；超过上限先提示。
- 分页：服务端分页；改筛选回第一页；数据减少回落合法页；保留页大小记忆。
- 状态：首次加载与后台刷新区分；空态区分「无数据 / 无筛选结果 / 加载失败」；失败保留已选条件。
- 反馈：批量操作显示逐项结果，部分失败保留失败项；成功不伪造数量。

## 2. 资源详情（抽屉）

适用：`HubStoreDetailDrawer`、`AssignmentDetailDrawer`、`WorkerDetailDrawer`、`WorkerTaskDetailDrawer`、`TaskDetailDrawer`、`RejectionDetailDrawer`、`PendingReviewDrawer`、`StoreDetailDrawer`。

- 结构：`AppDrawer`，头部固定、内容独立滚动、底部高频操作固定。
- 导航：上一项/下一项仅在稳定查询范围可用；边界禁用；按原筛选排序跨页。
- 只读与编辑：只读不出现回收/提交等写操作；编辑有未保存变更时启用关闭守卫。
- 证据：图片使用完整序列连续浏览；缺失如实提示，不拿失败画面冒充当前证据。
- 复制：ID、路径、错误摘要可复制，敏感字段脱敏。
- 刷新：自动刷新不令已打开详情消失；不存在或已回收给出明确原因。

## 3. 工作台（Hub / Worker）

适用：`HubWorkbenchPage`、`WorkerWorkbenchPage`、`RemoteControlPage`。

- 首屏：当前运行状态与最常用操作在最易见位置；区分运行、暂停、等待人工、异常、终态、待同步。
- 操作：开始/暂停/恢复/终止/同步按权限显示；禁用给出原因；开始前做前置检查。
- 实时性：状态轮询失败保留最近数据并标注时效，不显示成「零任务」或「独立模式」。
- 远程小窗：关键按钮、当前门店、等待状态、进度与连接时间在常用尺寸可见；辅助说明折叠。
- 安全：关闭/浮窗不停止采集；不抢焦点；不扩大远程接口权限。

## 4. 设置中心

适用：`SettingsPage` 及通知、共享连接、模型、目录、采集、日志、关于。

- 布局：`SettingsLayout` 分类导航 + 内容；窄屏改为顶部横向分类。
- 行：`SettingRow` 左标题/说明、右控件；复杂规则进帮助或高级区。
- 保存：本地偏好即时保存；服务端配置显式保存；`SettingsSaveBar` 显示未修改/已修改/保存中/失败。
- 草稿：后台 refetch 不覆盖编辑；离开分类或页面有未保存变更时确认。
- 角色：Hub/Worker 只显示实际适用分类与事件；受限页不展示无效能力。
- 危险清理：与正常保存分离，说明作用范围与保留内容，处理中不可误关。

## 5. 表单与多步任务

适用：`StartRunDialog`、`ImportBatchDialog`、`PublishDialog`、`AssignDialog`、`PairingDialog`、`AnalysisDialog`。

- 字段：`FormField` 建立 label/输入关联；单位、范围、必填、行内错误清晰。
- 提交：单一主操作；提交中禁用并防重复；失败保留输入并定位错误。
- 取消：区分「取消上传/取消任务」与「关闭界面」；关闭不隐式取消后台任务。
- 危险确认：`ConfirmActionDialog` 说明对象、范围、结果与可恢复性；处理中禁止误关。

## 6. 诊断与维护

适用：`DiagnosticsPage`、设置中的日志清理。

- 信息层次：总体状态 → 检查项 → 详情；只读检查与会影响桌面的动作分开。
- 动作：刷新、复制摘要、手动复制降级；运行中采集不被诊断抢占窗口。
- 恢复：失败给出最短可行修复路径；技术详情按需展开；复制内容脱敏。
- 导航：设置、诊断、版本信息可互相定位，不重复大段说明。

## 7. 图片与证据

适用：`ImagePreview` 及所有证据入口。

- 默认只读；缩放、平移、旋转只作用于预览。
- 多图必须传完整序列；当前索引与总数量可见；左右键切换，边界明确。
- 加载、失败、重试与窄屏工具栏可用；关闭回焦触发元素。
