# 设置、连接、通知、模型用量（/settings）

参考 Carbon 表单/内容规范、现有 SettingsLayout。目标是找到需要调整的参数，清楚改动作用于哪一实例以及何时生效。

```text
设置
分类导航（角色过滤）        | 当前分类标题
目录 / 模型服务             | 设置行：左名称·必要说明   右控件
采集配置 / 存储与日志       | 相关次操作 / 状态与错误
通知与提醒 / 设备与连接     |
软件更新 / 关于             | [放弃修改] [保存修改]（仅服务端有草稿）
```
现有 UpdatesPanel 可作为关于内独立子区，但左导航必须有明确「软件更新」锚点或独立分类，避免用户滚完整关于页；保持同一实例设置，不引入重复页面。分类按角色显示；Hub 不出现本机桌面/目录选择无效控件；Worker 显示适用本机参数。只显示适用事实，不能从角色名字猜测权限。
- 目录：输入/输出路径、选择/复制（原生选择仅支持角色）、保存影响提示；完整路径可查看，不以长路径撑乱界面。
- 模型服务：供应商、模型、接口地址、API 密钥（仅显示是否已设置，不回传）、清除密钥独立确认、思考模式、请求超时。连接测试与保存明确使用草稿还是已保存配置，以实际后端为准；结果就地提示。唯一入口「查看模型用量」。
- 采集配置：就餐人数、最大页数/Agent 步数、单任务上限、稳定等待等有效参数按任务/执行分组；单位和范围明确，运行中禁止保存的原因显示。自动控制的窗口尺寸/重叠比例仅高级只读区；素材分析并发属于实际适用实例，不能误称采集并发。
- 存储与日志：当前空间与上限、清理调试日志/截图（保留业务数据）、最后结果；危险操作独立，不与正常保存混在一起。软件版本清理由 updates.md 区分，避免两个相同清理入口。
- 通知与提醒：事件开关、提示音总开关、音量（真实百分比）、测试、桌面通知权限/请求入口、等待重复频率、连续处理偏好（如现有位置适用）。明确浏览器本地即时保存，不影响另一机器；拒绝权限不关闭站内提示。
- 设备与连接：Hub 管理入口；Worker 配对地址、设备名、码、状态、最近连接/待补传、失败恢复与诊断跳转。不要把配对失效当普通离线；保存前明确是否改变连接。
- 关于：当前运行版本、前端产物标识（技术详情）、角色和维护入口；不把源码版本、安装版本、运行版本混用。

服务端配置显式保存，草稿不被轮询覆盖；保存失败保留输入，放弃/切换/离开正确确认。立即生效的偏好不显示假保存按钮。

## 模型用量（ModelUsageDialog）
采用宽数据弹层：标题及统计口径 → 日期范围/用途/采集轮次/维度 → 已知调用数、输入/输出/总 token、成功/失败、可核实费用（无则未记录） → [统计/调用明细] → 统一表格及分页。默认范围沿用真实现有设置，明确时区；常用日期可快捷选择，不新增假费用。统计按维度，点击分组进入对应明细，显示当前下钻范围及「返回统计/清除门店筛选」，保留上级条件和页码。长模型名、ID、错误可复制/展开，未知用量与 0 区分；API 成功不代表采集成功。明细请求/响应只展示授权脱敏摘要。两张原生表格统一 AppDataTable，保留分组、展开、筛选、分页等已有能力，非仅换样式。
验收：模型密钥不可见，失败不丢输入；用量下钻返回保持条件；音量/测试与保存语义清楚。
