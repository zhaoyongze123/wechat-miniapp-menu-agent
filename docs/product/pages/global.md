# 全局导航、任务入口与反馈

入口：AppShell、RoleProvider、ActiveTaskIndicator、UnsavedChangesProvider、未知/历史路由。参考 Cloudscape 应用布局、Airflow 运行定位。

目标布局：
```text
侧栏 [菜单采集工作台] | 顶栏 [当前运行 N 项] [角色/连接]
     角色内导航       | 主内容 [页面标题        主操作]
     底部角色/连接     |       [页面具体工作区]
```
Hub 页面在侧栏导航上方提供项目选择器；业务页路由携带稳定 `project_id`，切换时保留当前页面和查询上下文并改为新项目数据。仅将上次项目保存在本地作为默认值，不覆盖 URL 中明确的项目。项目加载失败、无效或无可用项目时显示相应空态，不能静默回退到其他项目。Worker 只显示其已知且获分配的项目；独立端不显示选择器。
宽屏侧栏可折叠并记忆，图标保留名称/提示；窄屏单套导航可横向访问，不额外第二套侧栏；角色与连接信息只需一处完整表达，紧凑顶栏可用状态摘要。删掉重复品牌/说明，不占操作首屏。当前页明确高亮，未知页给「返回采集工作台」，旧 hash 跳正确目标。

**活动任务入口不是仅显示数字。** 任意业务页可展开当前运行摘要（名称、设备/来源、真实进度、状态、更新时间）；点击直接进入该轮任务详情。允许从此处执行本角色有权的当前任务控制，或一步进入已定位的可控制面板（详见 task-center）；Hub 的远程 Worker 只读，不新增远程暂停/终止。素材分析可直接进入相应作业。收起与打开不影响任务。无活动时不制造一个空卡片；连接失败显示最近可靠状态及更新时间。

活动任务属于运行自身的项目，不因当前项目选择变化而重新归属；跨项目全局状态只展示确实存在的运行及其项目，不把它混入当前项目业务列表。

全局反馈遵循 experience-contract：不反复 Toast 同一个轮询错误；保存/处置失败在原界面可重试；任何导航（返回/前进、深链、程序化跳转、弹层关闭）未保存草稿确实受保护。界面恢复时保留范围和焦点。
