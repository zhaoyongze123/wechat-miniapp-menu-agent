# 素材清洗、批次与返工（/materials）

参考 Label Studio 数据管理与单任务工作区。目标是大批量门店高效选码并安全发布。遵循 #20 门店级版本、原批次身份和像素判定。

批次、门店素材、发布快照及选码范围属于当前项目。批次同名不代表同一批次；跨项目切换不得复用草稿或已选门店。归档项目只读。

## 批次视图
```text
素材清洗                                   [新建批次]

待审核 / 已确认 / 不合格 / 已选码待发布（可靠数据）  分析状态
[开始/查看分析/重新分析（按状态）] [发布已确认门店（具备资格时）]
决策筛选 | 搜索门店 | 清除筛选
门店 | 选码决策 | 推荐/校验摘要 | 有效素材版本/发布状态 | 操作
分页
```
主动作按阶段：无批次→新建；待分析→开始分析；分析结束→打开待审核；可发布时突出发布。批次管理为次操作；避免「管理批次、分析、发布、用于采集」全都是主按钮。当前供采集使用范围如有既有真实作用，准确标识，不将整批快照设为单店版本。
门店表可进入详情，支持按待审核、已确认、不合格筛选及批量分析已有能力。统计与筛选同范围；分析作业与选码决策分开。

## 单店选码工作区（StoreDetailDrawer / ManualQrCanvas）
采用宽工作区而不是狭窄普通详情抽屉：
```text
门店名称 · 原批次 · 位置 N/M                  [上一家] [下一家] [关闭]
当前决策 / 已发布版本 / 返工状态（若有） / 必要原因
┌ 原图列表（缩略图） ┬ 原图大预览/框选 ┬ 候选二维码与信息 ┐
│ 切换原图           │ 缩放/旋转/查看原图 │ 推荐、选中、不可用原因 │
└───────────────────┴───────────────────┴────────────────────┘
补图（按需展开） / 单店重新分析 / 显示低质量候选 / 重置（按实际资格）
[标记不合格] [确认选码] （连续处理开启时成功进入下一家）
```
原图切换与候选定位双向联动，推荐不等于选中；低质量候选默认按现行规则展示/隐藏，可查看原因；候选归属原图清晰。人工框选与清空保留，坐标和最终裁剪一致。预览旋转/缩放不修改素材。没有可用图时给补图入口，不用空白框；补图「追加图片」「替换图片」区别说明，替换确认实际影响，上传失败保留文件/草稿。重新分析不自动覆盖人工确认或发布，按真实作用范围确认。窄屏按原图→候选→决策顺序；底部操作可达。
确认、跳过/不合格（原因+其他说明）、撤销/重置决策、上一/下一家均保留合法入口。关闭、切换批次/门店、后台更新时草稿保护；确认成功才继续。显示「已选码待发布」，不把确认当发布。

## 弹层
- 新建批次：批次名称、说明、浏览器文件/目录上传（本地路径仅在真实角色支持时），数量/格式、真实上传进度、取消上传与关闭区分；部分失败保留可恢复信息。
- 分析：当前 job 进度、暂停/继续/取消、失败重试与历史/明细；关闭只关闭 UI；重新分析可按选中门店或明确范围操作，说明是否覆盖人工结果。
- 批次管理：列表、名称/备注、已发布状态、删除进入回收站、恢复、永久删除及不可删除原因。永久删除独立确认，数据依赖/占用由服务端。
- 发布：显示批次、拟发布门店/实际变化、同图不升版、待处理/阻塞、备注、历史发布记录和切换默认范围（如真实支持）；确认发布，不自动启动采集。失败保留范围。

## 全部批次返工（ReworkPanel）
统计待重新选码、不合格、已选码待发布、涉及批次；筛选分类/原批次（有实际能力）、搜索；表格门店·原批次、返工原因、当前选码决策、门店版本、发布资格、操作。打开处理定位原批次门店工作区，返回原返工筛选。选中后按合法项显示「打回选中门店」「发布已选门店」与明确影响，跨批次发布按各原批次，部分失败留项。不可把重采当返工、打回自动重跑或重选后自动解除阻塞。
验收：仅 A 店换图发布，B 状态不变；A 同图重新发布解除打回但不升版、不自动重采；批量分析/发布部分失败可恢复；可持续连续审核。
