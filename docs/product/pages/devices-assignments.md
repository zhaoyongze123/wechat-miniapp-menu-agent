# 采集电脑与分配记录

采集电脑、配对和连接是实例级全局资源；分配记录保留所属项目，并在业务列表中按当前项目筛选。切换项目不复制设备、不改变分配归属；归档项目的历史分配只读。

## 采集电脑（/devices）
页头「采集电脑」+「配对采集电脑」。概览：已配对、在线、占用门店、待补传（各自真实范围）。列表：采集电脑名称 | 连接状态/最近连接 | 当前占用 | 待补传 | 配对时间 | 详情。已移除设备默认隐藏，有独立开关；设备多时搜索仅在支持真实名称/ID 筛选时使用，不因数量少伪造功能。设备在线和最近运行上报分别显示。

设备详情：名称与连接摘要置顶 → 当前运行/占用、已下载、待补传 → 最近连接/配对时间/稳定 ID → 「查看该电脑的分配记录」（携带 worker ID） → 名称、备注编辑/保存 → 独立危险区「解除配对」「从列表移除」。保留历史；活跃分配等阻塞原因就地解释。返回保持设备列表，能恢复目标设备详情上下文。保存失败不丢草稿。
配对弹窗：一次性码、有效期、复制、剩余有效时间（可靠时）、到期重新生成，说明在 Worker 设置填写地址/设备名/码；不伪造成功配对，配对后刷新设备列表。

## 分配记录（/assignments）
```text
分配记录                                [刷新]
采集电脑 | 分配状态 | 搜索门店/批次 | 清除筛选
[已选 N 条可回收分配 / 清空 / 回收选中]
□ 门店·批次/素材版本 | 采集电脑 | 分配状态·同步 | 时间 | 操作
分页
```
从设备进入显示「返回采集电脑」及设备筛选。每条为 assignment，不将轮次结果当作分配状态。详情：当前/历史标识、真实门店与版本、设备、分配/下载/结果上传时间、有效占用、结果去向、文件预览；历史只读。稳定范围连续查看。可回收项提供「回收分配」，不可回收说明原因。
回收确认必须说明 N 家、设备、解除占用及离线迟到结果留档；成功后显示实际回收数，保留失败项；提供现有「重新分配」入口（仅成功且仍有资格的任务，重新生成分配身份），不隐式重分配。设备页、工作台、任务中心的入口共用同一分配视图/过滤，不创建第二套。
验收：同门店多轮分配、离线回收与迟到历史结果；从设备→分配→详情→返回不丢上下文；批量部分失败可继续。
