# 远程半自动控制与置顶窗口

#26/#30 的真实操作场景：操作者自己的电脑通过远程桌面操作目标 Windows 微信，同时在本地浏览器 Document PiP 点击开始截图。不是 Hub 远程操纵桌面的新接口。

```text
设备名 · 连接状态                  [关闭/返回普通页]
当前门店（长名可查看）
轮次进度 N/M · 当前等待状态 · 最近更新时间
请进入点餐菜单，完成后点击开始截图
[开始截图] [标记不合格]  （已有合法跳过/快捷键按权限）
[测试提示音/快捷键与通知（次级）]
```
普通远程页与 PiP 复用 ManualPanel 状态和原因表单。常用紧凑窗口首屏保持当前店、进度和操作，不靠滚动找到开始截图；次级说明折叠。等待时按钮可用，非等待/提交中/连接过期禁用并说明；失败保留实际状态、恢复后重新核实当前上下文。发出操作绑定设备/run/任务/状态，不能在断线后自动重放。
支持 F8/F9 等现有快捷键和启停，输入原因时不得误触。测试提示音不需要桌面通知授权；等待事件每次提醒一次，按用户设置重复；浏览器音频限制清楚。打开置顶窗需实际能力和用户动作，失败可退普通独立控制页，不声称普通窗口系统置顶。复用窗口，不轮询抢焦点；关闭浮窗不终止采集、不影响微信截图范围。
验收：真实 HTTPS/PiP 能力按已有证据或受影响时隔离复验；断线禁止旧命令、关闭不停止、长店名/原因表单小窗可操作。
