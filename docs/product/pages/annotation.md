# 人工标注（/annotation）

Worker 专用。参考 CVAT 编辑器及 Label Studio 的数据队列；重点是画面和真实动作，不是展示技术参数。

```text
人工标注                                      [开始标注/结束会话]
┌ 门店队列 ┬ 当前门店 · 实时/历史 · 步骤 ┬ 操作区 ┐
│ 状态筛选 │ 大画布（截图、框选、建议虚线） │ 品类/目标/备注 │
│ 勾选/数量 │ 刷新截图、缩放、证据预览 │ 硬负样本、采纳建议 │
│ 当前店高亮 │ 历史步骤 上一/下一/退出回看 │ 提交/清空框选 │
└─────────┴───────────────────────┴────────┘
[暂停/继续] [完成门店] [跳过] [标记不合格] [重试]
```
队列只选后台可标注的本机任务，选中数量/不可选原因明确；开始后保留会话与当前任务，避免自动采集同时占用桌面。左侧可折叠，画布优先，窄屏有清晰队列/操作区域切换且关键动作不藏起。
当前截图与历史画面明显区分；历史只读，不显示可执行提交。建议位置虚线/文字说明，人工框选为另一视觉状态；「采纳建议位置」才变成实际框选，不自动点击。系统判断默认摘要，必要理由/候选按需展开。坐标映射基于原图，不受显示缩放影响，刷新/帧变化后旧框选不能提交。类别、目标、备注和硬负样本保留；硬负样本帮助只在相关控件旁说明适用场景。点击提交前核对当前画面身份；错误保留草稿/可重试。
完成、跳过、标记不合格、重试、暂停/继续、结束会话分别命名并说明真实后果。跳过不等于不合格；判退原因与补充失败保留。退出回看/刷新/换门店/关闭保护草稿。操作步骤历史和动作前后证据可查，技术详情默认折叠。
验收：框选在缩放前后映射一致，建议采纳不自动执行，历史回看不能点击微信；一次合法提交、失败后重试、暂停与继续、判退/跳过。
