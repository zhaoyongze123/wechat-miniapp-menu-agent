# 软件更新与版本治理

依据 #32 当前及后续已验收真实能力；基线 ce2856b 包括 Hub 更新执行器与存储治理，集中更新等后续功能以最终 #32 为准。参考 Cloudscape 生命周期模式；本规格不增加自动安装或远程控制权限。

```text
软件更新
当前运行版本 | 最新可用版本 | 最近检查时间及状态
发布说明（真实版本/渠道）                   [检查更新/下载/安装]
当前下载或安装进度、错误/恢复（有活动时）
更新偏好：发布渠道、自动检查（真实支持项）
版本管理：运行/已安装/待切换、受保护版本、回滚入口（有资格）
存储治理：可回收空间、预览清理范围、确认
更新历史：检查/下载/安装/回滚/清理（真实持久化记录）
```
主动作随状态互斥：未检查/失败→检查更新；可更新→下载；正在下载→进度及取消；已验证且具备安装资格→安装；阻塞→原因及合法恢复。旧版本 completed 不禁用新版本下载。显示目标版本、大小、发布渠道和实际文件校验状态；清单校验不是签名真实性，按后端证明如实显示。状态过期不得显示「已是最新」。下载失败保留可恢复进度；不假造百分比/预计完成时间。
安装确认列目标/当前版本、重启/采集影响、保留数据及真实回滚条件；正在采集或无安全资格不能执行。独立执行器期间允许关闭浏览器不取消后台任务，状态重连读取 journal/运行事实；仅健康验证成功显示更新完成，失败/已回滚/需人工恢复分别处理。不声称全部平台能力相同。
版本管理区区分当前、保护、待安装、可清理；回滚需明确相容性和数据影响，未支持的回滚不显示按钮。高级诊断以服务端事实显示实际交付方式、补丁基线、更新包大小和全量回退原因；OCI 取不到可靠网络字节数时只展示阶段，不伪造下载进度。存储清理先预览候选、保护原因、空间估计，再确认清理，结果真实；禁止把业务素材/截图/数据库列为可删。清理风险与安装区分。
Hub 设备集中更新仅在 #32 实际提供后呈现：设备状态、当前/目标版本、分批目标、授权/阻塞、进度与失败；不把离线设备标为成功、不默认全选全量升级。与设备页同一事实源。Hub/Worker 本实例更新与设备分发不得混淆。
验收：下载旧完成→可下载新；检查失败/过期；采集运行阻塞安装；成功与回滚真实；清理预览保护当前及必要回滚版本。复用 #32 的隔离安全验证，不额外重复打包。
