# 环境与连接诊断（/diagnostics）

Worker 专用。目标不是展示全部技术检查项，而是在无法采集、连接失效或模型错误时找到原因并恢复。参考 Airflow 逐级日志下钻与 Carbon 错误反馈。

```text
环境与连接                                    [刷新检查]
总体状态：可采集 / 有阻塞 / 未检查（真实资格与时效）
阻塞项（先显示）：微信桌面、执行引擎、模型、共享连接
检查项 | 状态 | 最近检查时间 | 简短原因 | 可执行恢复动作
高级诊断（折叠）：原始检查项、连接事件、技术详情
[复制诊断摘要]
```
区分浏览器到本机服务失败、Worker 到 Hub 离线、凭据失效、模型不可达及桌面环境问题。每项给实际原因与最短恢复路径（重新连接/前往设置/重配对/刷新）；只有已有真实能力才提供测试/重连。只读检查与会影响微信窗口的动作分开；运行中禁止抢占桌面，提示何时可检查。旧 UiPath/macOS 兼容项按当前平台实际适用展示，避免作为常规阻塞误报。
摘要复制采用公共 CopyButton/脱敏，失败给手动复制弹层。技术检查可展开，默认不展示原始长路径、令牌或客户素材。刷新保留最后成功结果并标记时间，不能把未知当正常或全部归零。连接/模型设置跳转定位相关分类。
验收：模型失败、连接离线/失效、微信不可用各自有不同恢复路径；采集中诊断不执行桌面动作；复制不泄露秘密。
